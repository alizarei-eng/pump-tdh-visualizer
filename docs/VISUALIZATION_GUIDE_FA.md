# راهنمای نسخه دسکتاپ Pump TDH Visualizer

## فناوری رابط کاربری

نسخه فعلی با **PySide6 (Qt)** ساخته شده است؛ بنابراین برنامه به‌صورت پنجره دسکتاپ اجرا می‌شود و نیازی به مرورگر یا Streamlit ندارد. نمودارها با Matplotlib رسم و مستقیماً داخل پنجره Qt نمایش داده می‌شوند.

## نصب و اجرا

Python نسخه 3.10 یا جدیدتر پیشنهاد می‌شود.

ساخت و فعال‌سازی محیط مجازی:

```bash
python -m venv .venv
```

در ویندوز:

```powershell
.venv\Scripts\activate
```

در Linux/macOS:

```bash
source .venv/bin/activate
```

نصب کتابخانه‌ها و اجرای برنامه:

```bash
pip install -r requirements.txt
python app.py
```

## امکانات رابط

- انتخاب مستقل پارامتر محور افقی X و محور عمودی Y
- تغییر دبی با Slider
- نمایش نزدیک‌ترین نقطه موجود در داده‌ها روی نمودار
- بارگذاری فایل CSV از ماشین‌حساب
- ابزارهای Zoom، Pan و ذخیره تصویر نمودار از نوار ابزار Matplotlib
- زبانه جداگانه برای نمودار، شماتیک هیدرولیکی و جدول داده‌ها

## نکته درباره تغییر دبی

در این نسخه، اسلایدر نزدیک‌ترین ردیف موجود در CSV را انتخاب می‌کند؛ محاسبه هیدرولیکی جدید یا درون‌یابی بین نقاط انجام نمی‌شود. برای محاسبه واقعی در هر دبی، باید رابط مشخصی برای فراخوانی موتور محاسباتی مخزن `pump-tdh-calculator` اضافه کنیم.

## داده نمونه

فایل `examples/sample_results.csv` صرفاً برای آزمایش رابط کاربری است و داده واقعی پمپ یا سایت محسوب نمی‌شود.

## ساختار CSV

ستون‌های موردنیاز:

- `flow_m3_h`: دبی، m³/h
- `tdh_m`: هد دینامیکی کل، m
- `velocity_m_s`: سرعت، m/s
- `major_loss_m`: افت طولی، m
- `minor_loss_m`: افت موضعی، m
- `hydraulic_power_kw`: توان هیدرولیکی، kW
- `shaft_power_kw`: توان محور، kW
- `electrical_power_kw`: توان برق ورودی، kW
- `pump_efficiency_pct`: راندمان پمپ، درصد
