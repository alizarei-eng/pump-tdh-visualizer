# راهنمای تصویری‌سازی ماشین‌حساب پمپ و TDH

## هدف پروژه

این مخزن فقط مسئول نمایش و تحلیل بصری نتایج است. محاسبات هیدرولیکی در مخزن مستقل `pump-tdh-calculator` باقی می‌مانند.

## اجرای برنامه

1. Python نسخه 3.10 یا جدیدتر نصب باشد.
2. محیط مجازی بسازید و فعال کنید.
3. وابستگی‌ها را نصب کنید:

```bash
pip install -r requirements.txt
```

4. برنامه را اجرا کنید:

```bash
streamlit run app.py
```

## کار با نمودار

- از فهرست Horizontal axis پارامتر محور افقی را انتخاب کنید.
- از فهرست Vertical axis پارامتر محور عمودی را انتخاب کنید.
- اسلایدر Flow rate دبی موردنظر را تغییر می‌دهد.
- نشانگر نمودار نزدیک‌ترین نقطه موجود در داده CSV را مشخص می‌کند.
- جدول داده‌ها در بخش Show selected row and source data قابل مشاهده است.

## نکته مهم درباره اسلایدر

در نسخه فعلی، اسلایدر محاسبات جدید هیدرولیکی انجام نمی‌دهد؛ فقط نزدیک‌ترین ردیف موجود در CSV را انتخاب می‌کند. بنابراین اگر دبی بین دو ردیف باشد، نشانگر روی نزدیک‌ترین ردیف قرار می‌گیرد. این رفتار تا زمان تعریف رابط رسمی اتصال به موتور محاسباتی عمدی است.

## ساختار داده ورودی

فایل CSV باید ستون‌های زیر را داشته باشد:

- `flow_m3_h`: دبی، مترمکعب بر ساعت
- `tdh_m`: هد دینامیکی کل، متر
- `velocity_m_s`: سرعت، متر بر ثانیه
- `major_loss_m`: افت طولی، متر
- `minor_loss_m`: افت موضعی، متر
- `hydraulic_power_kw`: توان هیدرولیکی، کیلووات
- `shaft_power_kw`: توان محور، کیلووات
- `electrical_power_kw`: توان برق ورودی، کیلووات
- `pump_efficiency_pct`: راندمان پمپ، درصد

## وضعیت داده نمونه

فایل `examples/sample_results.csv` فقط برای آزمایش رابط کاربری ساخته شده و نباید به‌عنوان خروجی واقعی پمپ یا سایت استفاده شود.
